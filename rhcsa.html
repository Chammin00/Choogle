COMPLETE ALL THREE TASKS
1. Systemd User Service PENDING

Create a systemd user service named logger-agent that runs the backup script `/usr/local/bin/logger.sh` every minute. Ensure the service file is placed in `~/.config/systemd/user/` and is enabled.

2. AutoFS NFS Auto-mount PENDING

Configure AutoFS to auto-mount export shares from NFS Server `10.0.5.50:/share` to dynamic target local path `/shares/remote`. Map file entries must reside inside `/etc/auto.master.d/` and `/etc/auto.shares`.

3. Podman Container Deployment PENDING

Deploy a container using podman named http-server from registry image `nginx:alpine`. Bind host port `80` to container port `80`, and mount host directory `/var/www/html` to container.

// BASH_COMMAND_CHEAT_SHEET

Systemd User:
• mkdir -p ~/.config/systemd/user
• systemctl --user enable logger-agent.service
AutoFS Setup:
• echo "/shares /etc/auto.shares" >> /etc/auto.master.d/shares.autofs
• echo "remote -fstype=nfs 10.0.5.50:/share" >> /etc/auto.shares
Podman Container:
• podman run -d --name http-server -p 80:80 -v /var/www/html:/usr/share/nginx/html:Z nginx:alpine
