// LAB_OBJECTIVES

CCNA EXAM PRACTICE TASKS
1. Configure R1 Interface PENDING

Elevate to privilege mode on R1. Assign IP address 192.168.1.1 255.255.255.192 to interface Fa0/0 and run `no shutdown` to change interface link state to UP.

2. Configure R2 Interface PENDING

Switch focus console node to R2. Assign IP address 192.168.1.2 255.255.255.192 to interface Fa0/0 and execute `no shutdown`.

3. End-to-End Ping PENDING

Once both interface links are up, return console focus to R1 and execute ping 192.168.1.2 to verify packet routing connection.
